# 云南自修学校 · 小程序演示版

给学校看的演示版。纯前端，没有后端：示例数据在 `data/mock.js`，登录、预约、订单、做题记录存在手机本地（`utils/store.js`）。正式版把 `store.js` 里的函数换成接口请求，页面不用动。

## 怎么打开

1. 安装微信开发者工具（Windows / Mac 都有）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开后用微信扫码登录
3. 解压本压缩包，在开发者工具里点「导入」，目录选解压出来的 `ynzixiu-miniprogram` 文件夹
4. AppID 一栏选「测试号」，点「确定」
5. 左侧模拟器就是小程序。手机画面显示不全的话，在模拟器上方的机型下拉里把缩放调到 85% 或 75%

不需要联网接口，也不需要安装依赖，导入即可运行。

真机扫码预览需要一个真实的小程序 AppID（个人主体可免费注册），填到 `project.config.json` 的 `appid`。

## 演示路线（约 5 分钟）

1. 首页：品牌、六大业务、直播课堂（正在直播 + 即将开播）、政策头条、热门课程、营销活动（分销 / 拼团 / 领券 / 海报）、上岸喜报、悬浮电话
2. 业务 → 统招专升本：适合谁、服务内容、相关课程，底部「预约一对一规划」
3. 预约表单：不用登录就能留资，提交后在「我的预约」能看到
4. 课程「专升本集训营」→ 目录里试听第 1 节 → 立即报名 → 登录（验证码 123456）→ 领一张券再到订单确认页选券立减 → 选「首付 + 尾款」→ 支付 → 电子收据
5. 回课程页：全部章节解锁，学习进度同步到「我的 · 学习中心」
6. 刷题：分科练习选完即判、答错自动进错题本；综合模考限时 10 分钟、交卷出分
7. 直播课堂：首页「正在直播」进直播间（演示）、即将开播场次预约开播提醒（订阅消息演示）、回放可看
8. 消息中心：「我的 · 消息中心」开启消息推送（订阅消息演示），消息列表支持已读
9. 营销活动：转介绍分销（推广码、收益、提现）、拼团（开团 / 参团 / 邀请）、领券中心（领取后订单确认页可用）、分享海报（canvas 生成、保存到相册、转发）
10. 内容批量录入：「我的 · 内容批量录入」查看题库 / 课程 / 资讯导入模板，支持复制模板与模拟导入
11. 我的：订单里付尾款、收据；页面底部「重置演示数据」可恢复初始状态，方便下一次演示

## 结构

```
data/mock.js        示例数据（业务、课程、资讯、题库、喜报、直播、消息、优惠券、拼团、分销）
utils/store.js      本地存储，代替后端（含直播提醒、我的优惠券、拼团、提现、消息已读）
utils/view.js       课程卡片字段加工
templates/course.*  课程封面与列表行（用业务色 + 字标生成，不依赖图片）
pages/              29 个页面，tabBar：首页 / 业务 / 刷题 / 我的
  live/             直播课堂：列表（直播中 / 即将开播 / 回放）+ 详情（开播提醒）
  message/          消息中心：订阅消息演示 + 消息列表
  marketing/        营销中心：分销、拼团、优惠券、分享海报
  admin/            内容批量录入：导入模板演示
assets/tab/         tabBar 图标
```

示例内容都标了「示例」；喜报、资质、协议、直播、营销数据正式上线前须由学校提供真实材料。新增功能均为前端演示：直播与消息推送、营销裂变、内容批量录入在正式版接入后端与第三方服务（微信直播 / 云点播、订阅消息、公众号模板消息、短信、支付、二维码 API 等）。
