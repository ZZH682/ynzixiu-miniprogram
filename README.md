# 云南自修学校 · 小程序演示源码

「五站合一」教育建站项目中**微信小程序端**的演示版源码（PC / H5 / 公众号 / APP 端不在本仓库）。

演示版为**纯前端**：示例数据在 `ynzixiu-miniprogram/data/mock.js`，登录、预约、订单、做题记录存储在手机本地。正式版将本地存储替换为接口请求即可，页面结构不变。

详细使用说明（微信开发者工具导入步骤、测试号配置等）见 [`ynzixiu-miniprogram/README.md`](./ynzixiu-miniprogram/README.md)。

## 快速开始

1. 安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 导入本仓库下的 `ynzixiu-miniprogram` 目录
3. AppID 选择「测试号」即可运行（无需联网、无需安装依赖）

## 技术栈

微信原生小程序（WXML / WXSS / JS）· 本地存储（storage）· 模拟数据
